# Лабораторная работа: Контейнеризация многокомпонентного приложения (Docker Compose)

## Вариант 18 — Онлайн-переводчик

Приложение «Онлайн-переводчик»: пользователь вводит текст и выбирает целевой язык,
сервис выполняет перевод и сохраняет его в историю запросов в базе данных.

**Функции Web-сервиса (по варианту):** перевод переданного текста на выбранный язык.
**Данные для БД:** история переводов.

## Архитектура

| Контейнер     | Технология                    | Порт (хост) | Назначение                                          |
|---------------|-------------------------------|-------------|-----------------------------------------------------|
| `frontend`    | HTML/CSS/JS + nginx           | `8080`      | Веб-интерфейс, проксирует `/api` на backend         |
| `backend`     | Python Flask + gunicorn       | `8000`      | REST API, работа с БД и вызов web-сервиса           |
| `db`          | PostgreSQL 16                 | —           | Хранит историю переводов, инициализация `init.sql`  |
| `web-service` | Python (микросервис-эмулятор) | `5001`      | Движок перевода текста на выбранный язык            |

Все контейнеры объединены в одну bridge-сеть `app_net`, порядок запуска задан через
`depends_on` с проверкой `healthcheck` базы данных. Данные PostgreSQL сохраняются в
именованном томе `pgdata`.

```
Браузер → frontend:8080 (nginx) → backend:8000 (Flask) → db:5432 (PostgreSQL)
                                                    ↘ web-service:5001 (переводчик)
```

## API backend'а

| Метод   | Эндпоинт        | Описание                                             |
|---------|-----------------|------------------------------------------------------|
| `GET`   | `/api/health`   | Проверка готовности backend и БД                     |
| `GET`   | `/api/languages`| Список поддерживаемых языков (от web-сервиса)        |
| `POST`  | `/api/translate`| Перевод текста (web-сервис) + сохранение в БД        |
| `GET`   | `/api/history`  | История переводов из БД                              |
| `DELETE`| `/api/history`  | Очистка всей истории (или одной записи `?id=N`)      |

Пример запроса перевода:

```bash
curl -X POST http://localhost:8000/api/translate \
     -H "Content-Type: application/json" \
     -d '{"text": "Добрый день!", "target_lang": "en"}'
```

## Запуск

Требования: Docker и Docker Compose.

```bash
docker compose up --build
```

Приложение доступно по адресу: **http://localhost:8080**

Остановка:

```bash
docker compose down          # остановить (данные БД сохраняются в volume pgdata)
docker compose down -v       # остановить и удалить данные БД
```

## Как проверить работоспособность

1. Открыть http://localhost:8080.
2. Ввести текст (например, «Добрый день!»), выбрать язык и нажать **«Перевести»** —
   перевод выполняется web-сервисом через backend и сохраняется в PostgreSQL.
3. Нажать **«Загрузить историю»** — backend читает сохранённые записи из БД
   (включая первичные данные из `db/init.sql`) и выводит их списком.
4. Записи в истории можно удалять поштучно; данные переживают перезапуск
   контейнеров за счёт именованного тома `pgdata`.
